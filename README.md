# MY\_cloud-resume-challenge

履歴書サイト on AWS

Cloud Resume Challenge - SRE Edition

\## 概要



The Cloud Resume Challenge を AWS で実装。SRE の観点から

可観測性とコスト最適化を重視した設計。



\## 使用技術



\- \*\*Cloud\*\*: AWS (S3, CloudFront, Lambda, DynamoDB, API Gateway)

\- \*\*Frontend\*\*: HTML, CSS, JavaScript

\- \*\*Backend\*\*: Python (Lambda)

\- \*\*IaC\*\*: Terraform (予定)

\- \*\*Observability\*\*: CloudWatch
