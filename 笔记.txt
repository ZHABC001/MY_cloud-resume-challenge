JSON = JavaScript Object Notation（JavaScript 对象表示法）
读音: 杰森

本质: 一种"数据交换格式"
作用: 让不同系统/语言之间能传递数据

具体场景:
   你的 Lambda（Python）  →  JSON  →  浏览器（JavaScript）
                       ↑
              不同语言的"通用语"

语法规则:
   "键": 值
    ↑     ↑
  字符串  任意类型
   双引号

例子
{
    "name": "Zhang"
}

 种值类型
{
    "字符串": "Hello",          
    "数字": 42,                  
    "布尔值": true,              
    "空值": null,                
    "数组": [1, 2, 3],          
    "对象": {"key": "value"}    
}


例子

{
    "name": "Zhang",
    "age": 27,
    "skills": ["AWS", "Python", "日本語"],
    "address": {
        "country": "Japan",
        "city": "Chiba"
    }
}
